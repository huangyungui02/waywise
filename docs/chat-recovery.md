# 会话执行与恢复

后台执行不依赖 HTTP 连接。一次运行由 PydanticAI 执行，官方 `VercelAIAdapter` 产生 AI SDK v6 事件；浏览器始终只发送本轮用户输入，模型历史仍由官方会话和步骤存储提供。

## 服务端

`replies.py` 使用官方 `redis.asyncio` 客户端，将适配器已经编码的事件通过 `XADD` 追加到每次运行独立的 Stream。Redis 自动生成的事件 ID（如 `1794200000000-0`）就是恢复游标，不再维护 SQLite 事件表、自增序号或进程内唤醒通知。

每个会话有一个指向当前运行的键，每次运行有一个元数据 Hash 和一个 Stream。元数据保存运行前的 UI 历史（包括本轮用户输入）及状态。读取恢复检查点时，先 WATCH 会话指针，再用 MULTI/EXEC 一起读取元数据和事件前缀；若指针在读取期间被下一轮替换或过期，则重新读取。检查点包含运行 ID、基础消息、截至游标的官方事件前缀和运行状态。

`GET /api/conversations/{id}/chat/stream?run_id=…&after=…` 使用 `XREAD BLOCK` 读取游标之后的事件。各连接独立读取，不使用消费组；多个页面都能收到完整输出。每条事件后附加官方 transient `data-progress`，确认浏览器已经应用的运行与游标，它不成为聊天内容。

结束时在同一 Redis 事务中更新状态、追加结束标记并设置过期时间；结束标记唤醒等待中的订阅者。已经完成的运行仍可读取尾部，避免详情读取与任务完成交错时漏掉输出。恢复检查点的游标可能已经包含结束标记，此时订阅直接结束，不再阻塞等待。

活跃运行不裁剪事件、不设置到期时间，避免长时间搜索或思考时丢失前缀。运行结束后，指针、元数据和 Stream 默认保留 24 小时，由 `REPLY_RETENTION_SECONDS` 配置。下一轮开始时替换指针并删除上一轮临时数据；删除会话也清理当前运行。事件到期后，读取会话回退到官方 SQLite 历史。IndexedDB 缓存仍会向服务端校准，不能把旧事件游标用于另一轮运行。

服务启动时根据 SQLite 会话列表收尾遗留的 Redis 运行，将其标为取消并追加结束标记。不会自动重跑模型或工具。当前仍要求单后端进程，因为执行归属、互斥和取消令牌由该进程持有；换成 Redis 不代表已经支持多 worker。Redis 丢失时无法保证未落入正式历史的临时输出，正式历史、步骤和 Trip 不依赖 Redis。

本地默认 `REDIS_URL=redis://localhost:6372/0`。Compose 使用官方 Redis 镜像、AOF 和独立 `redis-data` 卷，通过容器内网连接；应用等待 Redis 健康后启动。连接池由 FastAPI lifespan 关闭。凭据 URL 在 Settings 中使用 SecretStr。

## 浏览器

`chat/transport.ts` 扩展官方 `DefaultChatTransport`，只负责拼接事件前缀和后续流，协议解析及文字、reasoning、工具状态的归并全部交给官方 Chat。当前 SDK 不能仅从公开 UIMessage 快照重建所有流内部索引，因此不自行实现服务端消息归并器，也不直接把消息快照与任意增量拼接。

恢复时先在 Chat 内完整消费检查点事件，再发出 transient 恢复标记，页面才切换为恢复结果；随后订阅尾部。打开尾部连接不能阻塞前缀还原，否则模型等待工具或思考期间可能迟迟没有新字节，已有进度也会被拖延。Redis Stream 事件游标保证两步之间产生的事件仍能补齐。

`chat/use-conversation.ts` 拥有聊天同步和缓存生命周期。路由重新验证仅更新会话和方案信息，不用历史整体覆盖正在接收的消息。切换会话或卸载只断开订阅；停止按钮显式取消后端执行。网络恢复或页面重新可见时重新同步。

## IndexedDB

`chat/cache.ts` 使用浏览器原生 IndexedDB，保存 schema version、会话、运行 ID、已应用游标及对应消息快照。消息在处理完 `data-progress` 时复制，消息与游标一起写入同一个事务；流式期间按 250ms 合并写入，完成和页面离开时尽力提交最近检查点。

缓存只用于立即预览。恢复总是读取服务端检查点，由官方 SDK 重新还原内部流状态；缓存游标不能直接当作新的 SDK 实例的订阅起点。恢复期间展示“正在同步最新进度”，以免把旧缓存误认为实时状态。读取失败、写入失败、缓存被清空或结构版本不匹配，都不影响服务端恢复。接口离线时可阅读已有缓存，网络恢复后重新同步。删除会话会删除本地缓存；服务端返回 404 时也会使该缓存失效。

此缓存不提供应用资源离线安装或 Service Worker。关闭浏览器期间是否生成取决于后台进程是否仍存活，IndexedDB 不负责执行任务。
